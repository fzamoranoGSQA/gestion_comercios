# 🔗 API Endpoints (opcional)

Si se habilita Django REST Framework:

| Endpoint | Método | Descripción |
|-----------|---------|-------------|
| `/api/comercios/` | GET / POST | Lista o crea comercios. |
| `/api/proveedores/` | GET / POST | Lista o crea proveedores. |
| `/api/servidores/` | GET | Muestra servidores con conteo de proveedores activos. |
